# Tic_tac_toe
This is a tic tac toe game for the NumWorks calculator to use with Omega, Upsilon, mu or a replacement. It require the get_keys() function from the ion module.
You can send it using https://xcas.univ-grenoble-alpes.fr/nw/nws.html or by coping it on a repo on your account on NumWorks or on the Upsilon Workshop.
